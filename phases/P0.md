# P0 — Operating rules
Prerequisite: Owner kickoff
Deliver: Decision register, service catalogue and routing inputs, permissions, payment policies, actual staffing and resource measurements.
Gate: Owner approves decisions or explicitly defers inactive features; no ambiguous price/unit active.
Read governing roadmap and relevant source sections. Orchestrator creates task breakdown, schema/API changes, fixtures and acceptance traceability before coding. QA independently verifies. Record evidence and request owner approval; stop at gate. No production changes by default.
